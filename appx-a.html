B2예측·추천기과거 데이터로 학습한 모델이나 비학습 최적화 알고리즘이 수치·등급·순위·이상점수를 내고, 사람이 이를 판단 자료로 쓴다(LLM은 쓰지 않는다).4↗

B4인식 파이프라인서류·음성·영상·도면 같은 비정형 입력을 인식 → 구조화 → 판정으로 연쇄 처리해 사람이 옮겨 적던 단계를 없앤다.34↗
B5현장 감지·경보카메라·드론·센서·PLC·재난 API 같은 상시 또는 주기 관측 스트림을 감시해 이상을 탐지하고 등급을 매겨 경보·조치 요청을 낸다.3↗
B6에이전트 오케스트레이터역할을 나눈 LLM들이 도구를 호출하며 계획을 세우고 다단계 업무를 이어 가며, 사람은 승인과 예외 처리를 맡는다.15↗
B7콘텐츠 생성기영상·카드뉴스·교육자료·정보지·기사처럼 산출물 자체가 콘텐츠인 것을 AI가 만들고, 사람이 검수·편집해 발행한다.12↗

B′ 제어 흐름 원형

패턴의도PAX 사용성좌
B′1순차 파이프라인한 단계의 출력을 다음 단계의 입력으로 넘기는 고정 순서 배선이다. 한 프롬프트에 많은 일을 몰아 시켜 품질이 떨어지는 문제를 막는다.109↗
B′2라우터·디스패처요청의 의도·유형·난이도를 읽어 전문 경로·모델·도구·담당자로 보내는 배선이다. 모든 건을 같은 경로로 보내는 낭비를 막는다.23↗
B′3병렬 팬아웃·수집의존성 없는 하위 작업을 동시에 돌리고 결과를 취합하는 배선이다. 구획형은 서로 다른 부분을, 투표형은 같은 작업을 여러 번 돌려 다수결로 합친다.8↗
B′4계층 분해·감독자상위 에이전트가 목표를 쪼개 하위 전문 에이전트에 위임하고 결과를 합치는 배선이다. B6 오케스트레이터의 기본 배선이다.2↗
B′5생성자-비평가생성과 검증을 분리해, 비평이 통과시킬 때까지 생성물을 고쳐 다시 만드는 배선이다. 반복 상한이 없으면 비용이 폭주한다.11↗
B′6반복 개선초안 → 비평 → 개선을 수치로 정한 품질 목표(정확도·길이·형식)에 도달할 때까지 순환하는 배선이다. 수렴 보장이 없어 최대 반복이 필수다.2↗
B′7ReAct 도구 루프생각 → 도구 호출 → 관찰 → 생각을 반복하며 답을 찾는 배선이다. 추론 흔적이 남아 근거 추적의 원료가 된다.16↗
B′8계획-실행계획자가 전체 단계를 먼저 쓰고 실행자가 그 순서대로 수행하는 배선이다. 중간 이탈이 비싼 긴 업무에서 단계 누락과 실행 무질서를 막는다.5↗
B′9결정론 판정 게이트판정 모델(LLM·VLM·비전 분류기·통계 모델)은 정형 출력만 내고, 규칙 엔진이 최종 판정·산수·분기를 하며, 사람 또는 시스템이 확정한다.17↗
B′10선게이트·후보축소규칙·검색·물리 특징 게이트가 먼저 후보를 좁혀 판정 모델 호출을 줄이는 B′9의 역방향 배선이다. v0.7 문서 개정 때 추가되었고 태깅 스키마에는 아직 반영되지 않았다.0↗
B′+기억 관리세션 안의 맥락과 세션을 넘는 장기 기억을 유지하는 배선이다. 공공에서는 개인정보 축적과 직결되므로 등급·비식별 없이 장기 기억을 두지 않는다.15↗

A2.2모델 서빙 · 주권형 온프레미스오픈웨이트 모델을 기관 서버·폐쇄망·로컬 PC 안에서 Ollama·vLLM 등으로 구동해 데이터를 기관 밖으로 내보내지 않고 추론한다.54↗
A2.3모델 서빙 · 튜닝형파인튜닝·LoRA·재학습으로 기관 업무에 맞춘 자체 모델을 서빙한다. 평가·접지·스킬로 풀리지 않을 때 가는 진행 경로의 마지막 단계다.1↗
A2.4모델 서빙 · 내부망 프록시행정망·내부망에서 상용 모델을 쓰도록 호출을 기관 게이트웨이·사설 엔드포인트·범정부 공통기반으로 중계해 반출과 접근을 통제한다.4↗

A2.6모델 서빙 · 벤더 블랙박스장비·상용 제품에 내장돼 기관이 모델·버전·학습 데이터를 보거나 바꿀 수 없는 모델의 자리다. 교체·재학습 대신 계약과 자체 실측으로 통제한다.4↗
A3공공 API 제공자정부·공공이 운영하는 모델·데이터·개발 도구(범정부 AI 공통기반, 모두의 AI 실험실, 공공데이터포털, 공공 깃랩)를 범정부 Provider로 소비한다.154↗
A4데이터 연계 서비스타 기관 데이터를 연계 계약과 표준 인터페이스·키 매핑으로 결합해 한 기관의 데이터로는 풀 수 없는 문제의 기준선을 만든다.11↗

A6지식그래프 서비스규정·업무 개념·관계를 온톨로지로 명시해 여러 업무 부품이 같은 개념 체계로 검색·추론하게 한다.13↗
A7자체 제작 환경외부 용역 없이 기관 인력이 저작도구·AI 코딩 에이전트로 도구를 직접 만들고 고치는 제작 환경이다.317↗
A8MCP 서버·호스트공공 API·업무 시스템·로컬 파일을 에이전트가 부를 수 있는 도구로 감싸고, 도구 목록·권한·호출 로그를 한 층에서 관리한다.94↗

C 운영 컴포넌트

패턴의도PAX 사용성좌
C1검토 큐AI 산출물이 다음 단계로 넘어가기 전에 사람이 맞고 틀림을 확인·수정·확정하는 대기열을 두어, 오류가 업무 결과로 흘러가지 않게 한다.46↗
C1.2심의 게이트팩트체크·법무·윤리 심의처럼 제3자 전문가가 수행하는 승인 게이트를 AI 산출물의 공개·반영 전에 두어, 업무 담당자 확인만으로 걸러지지 않는 법적·사실적 위험을 막는다.3↗
C2위험도 라우터건별 위험도·신뢰도를 매겨 저위험은 자동 처리, 중간은 검토 큐, 고위험은 숙련자에게 보내 사람의 검토를 필요한 곳에 집중시킨다.4↗
C3상태 머신·롤백건이 끝났음을 시스템이 알게 하고, 잘못 처리된 건을 되돌리는 경로(롤백·재처리·이의제기)를 제공한다. 여러 시스템에 걸친 처리는 보상 트랜잭션으로 되돌린다.6↗
C4감사 로그·지표처리 건마다 흔적을 적재하고 수정률·처리시간·자동처리율·가용성을 집계해, '지난달 수정률'을 숫자로 답하게 한다.16↗
C5가드레일 필터개인정보·환각·편향·형식 오류가 프롬프트나 산출물에 들어가지 못하게 시스템이 경계에서 걸러낸다. 비식별 전처리, 출처 검증, 구조적 출력 제약이 대표 변형이다.44↗
C6환류 파이프라인사용 결과(수정·이의·오탐 기록)가 정해진 주기와 트리거로 재학습·기준 개정에 되돌아오게 해, 배포 뒤에도 성능과 기준을 계속 고친다.3↗
C7폴백 스위치모델·API·도구가 멈추거나 품질이 떨어질 때 대체 모델·규칙 기반 축소·수동 처리로 경로를 바꿔 서비스가 끊기지 않게 한다.12↗
C8권한 경계·킬스위치AI 부품이 할 수 있는 일의 상한을 P0~P4로 못 박고, 도구별 실행 승인·읽기/쓰기 분리·속도 제한·즉시 중단 스위치를 제공한다.22↗
C9평가 세트·회귀시험배포 전에 업무 맥락의 질문·정답·채점 기준을 세트로 만들어, 프롬프트·모델·설정의 모든 변경을 같은 자로 재고 회귀를 잡는다.15↗

패턴의도PAX 사용성좌
S1AI 게이트웨이·단일 진입점모든 모델·도구 호출이 하나의 진입점을 지나게 해 인증·인가·요청 상한·감사 기록·비용 상한을 일괄 적용한다.3↗
S2권한 인식 검색검색·생성 전에 요청자의 권한으로 문서 단위 접근을 판정해, 모델이 볼 수 없는 문서는 검색 결과에도 나타나지 않게 한다.2↗
S3컨텍스트 방화벽시스템 지시·장기 기억·검색 결과·도구 출력·이용자 입력을 신뢰 등급이 다른 구역으로 나눠 표시하고 섞이지 않게 한다.3↗
S4행동 선택기LLM은 자연어 요청을 미리 정의된 행동 목록이나 자리만 채우는 템플릿 질의 중 하나로 번역만 하고, 행동 결과는 LLM으로 되돌아오지 않게 한다.0↗
S5계획 후 실행·코드 후 실행신뢰 불가 데이터를 읽기 전에 도구 호출 계획이나 프로그램을 고정하고 정책으로 검증해, 도구 출력이 새 행동을 끼워 넣지 못하게 한다.1↗
S6격리 LLM·맵리듀스도구를 가진 권한 LLM은 신뢰 불가 데이터를 읽지 않고, 데이터를 읽는 격리 LLM은 도구가 없게 나눈 뒤 결과를 형식 제약이나 기호 참조로만 넘긴다.0↗
S7컨텍스트 최소화이용자 입력이 행동을 결정한 뒤에는 그 입력을 컨텍스트에서 제거하고 조회 결과만으로 답을 만들어, 이용자가 넣은 인젝션이 응답을 조작하지 못하게 한다.0↗
S8독립 검증기·이중 심판주 모델과 분리된 프로세스·모델·규칙이 입력의 탈옥·인젝션·PII와 출력의 유해·유출을 검사해 차단·경고·재작성한다.0↗
S9임시 샌드박스에이전트가 만든 코드·명령을 일회용 격리 환경(컨테이너·microVM·제한 런타임)에서 실행하고 끝나면 파기해, 호스트·행정망은 결과값만 받게 한다.1↗
S10결정적 재생프롬프트·검색 결과·도구 호출·정책 결정·실행 흔적을 순서대로 기록해 사고를 그대로 재현하고 책임을 부인할 수 없게 한다.0↗
S11인제스천·공급망 검증코퍼스·임베딩·MCP 서버·스킬·패키지를 들여올 때 악성·출처·오염·의존성·라이선스 검사를 비동기로 거친 뒤에만 활성화한다.1↗
S12데이터 비도달 설계개인정보·원문을 단말(브라우저·PC·기기)에서 처리해 서버나 외부로 아예 보내지 않는다. v0.6 후보 부품으로, 카드 없이 R4 한 줄 정의와 §13 레지스트리로만 등재되어 있다.36↗
S13로컬 비식별 게이트외부로 전송하기 전에 단말·현장 서버의 소형 모델로 개인정보를 탐지·마스킹해 비식별 결과만 내보낸다. v0.6 후보 부품으로, 카드 없이 R4 한 줄 정의와 §13 레지스트리로만 등재되어 있다.5↗

F 상호작용 패턴

패턴의도PAX 사용성좌
F1출처 표시답변에 근거 문서·조문·통계표 ID를 붙여 이용자가 원문을 직접 확인하게 한다. C5 출처 검증의 이용자 면이다.87↗
F2편집 가능한 출력생성물을 이용자가 직접 고쳐 확정하게 한다. 이용자의 통제감은 여기서 나오고, 수정 내역은 C4 지표와 C6 환류의 입력이 된다.50↗
F3결과 대안·부분 재생성한 요청에 여러 안을 주고 일부만 다시 만들게 해, 첫 결과가 마음에 들지 않을 때 전체를 다시 요청하지 않아도 되게 한다. B′6 반복 개선의 이용자 면이다.7↗
F4구조화 입력빈 프롬프트 대신 서식·단계별 입력·조건 선택으로 안내해, 필요한 정보가 빠지거나 규정 밖 요청이 들어오는 것을 입구에서 막는다. D2 접수의 면이다.44↗
F5참고자료 첨부이용자가 파일을 붙여 답의 범위를 좁힌다. A10 어댑터(HWPX·PDF)가 뒤에서 받치고, C5 비식별이 첨부 직후에 걸린다.15↗
F6에이전트 행동 검토·확인에이전트가 무엇을 하려는지 먼저 보여 주고 이용자의 확인을 받은 뒤 실행한다. C8 권한 경계와 C1 검토 큐의 이용자 면이며 P2 이상에서 필수다.11↗
F7한계·신뢰도 안내AI가 무엇을 못 하는지, 얼마나 확신하는지, 공식 판단이 아님을 이용자 눈에 띄는 곳에 적어 과신을 막는다.63↗
F8대화 이력·되돌리기이전 요청과 결과를 다시 열어 보고 되돌리게 한다. C3 롤백의 이용자 면이며, 장기 보관은 B′+ 기억 관리의 개인정보 규칙을 따른다.5↗
F9판정 근거·기여도 표시SHAP 요인 문장, 의심 부위 BBox, 판정 사유 코드, 자연어 판독 이유, 예측-실제 잔차로 모델이 왜 그렇게 판정했는지 보인다. B2·B4·B5의 필수 면이다.23↗
F10이용자 자기확인·피드백최종 이용자가 AI 인식 결과를 '정확함/틀림'으로 확인만 하거나 응답 만족도·오류를 제보하는 단계다. 담당자 검수(C1)나 편집(F2)과 구별되며, C6 환류에 이용자 쪽 입력을 댄다.3↗
F11진행 상태·핸드오프 안내단계별 처리 진행률, '상담원을 연결합니다' 같은 사람 이관 고지, 대기 예상 시간을 보여 준다. C2 라우터가 사람에게 넘길 때 이용자가 보는 면이다.2↗

D 서비스 블록

패턴의도PAX 사용성좌
D1안내·탐색국민이 어떤 서비스를 받을 수 있고 어디로 가야 하는지 알려 주는 대민 접점 블록이다. B3 지식 접지나 B0 탐색기가 이 자리에 들어간다.99↗
D2접수·제출국민이 신청하고 서류를 제출하는 대민 접점 블록이다. B4 인식 파이프라인이 서류를 읽고 자동 보정·오류 안내로 제출 품질을 올린다.9↗
D3자격·심사요건 충족과 규정 준수를 판정하는 대민 접점 블록이다. B4·B1이 판정 재료를 만들고, C2 위험도 라우터가 붙어야 First가 된다.5↗
D4분류·이관국민의 상황을 듣고 적절한 부서·서비스로 보내는 대민 접점 블록이다. B3·B6가 이 자리에 들어가고 C2 라우터가 기술적 실체다.1↗
D5통지·추적언제 무엇을 해야 하는지, 어디까지 왔는지 알려 주는 접점 블록이다. B5 경보와 공문→할 일 카드(D-day)가 이 자리에 들어간다.2↗
D6점검·감시시설·환경·안전을 상시 또는 주기적으로 점검하는 현장 접점 블록이다. Levine 목록에 없어 이 카탈로그가 추가했으며, B5·B2가 이 자리에 들어간다.5↗
D7상담·처방개인 상황에 맞춘 정보·처방·법령 안내를 주는 대민 접점 블록이다. B1 코파일럿이나 B3 지식 접지가 이 자리에 들어간다.14↗
D8.0기타·범용동작 키워드로 판정되지 않는 내부 운영 도구(범용 플랫폼·에이전트 개발 환경·교육)를 담는 블록이다. 다음 판에서 하위 블록을 추가할 후보군이다.45↗
D8.1탐색·조회데이터·법령·공고·선례·타 지역 사례를 찾아 담당자 화면에 놓는 내부 운영 블록이다. B0 탐색·시각화, MCP 도구 제공, B3가 전형 부품이다.176↗
D8.2요약·추출공문·회의록·공람 문서에서 무엇을 언제까지 해야 하는지를 뽑아 카드·일정으로 만드는 내부 운영 블록이다. B1, B8 오버레이, B4가 전형 부품이다.24↗
D8.3초안·기안보고서·공문·답변·직무기술서·제안서의 첫 판을 서식에 맞춰 만드는 내부 운영 블록이다. B1 스킬 코파일럿에 A9 규범 스킬과 A10 HWPX 어댑터가 붙는다.64↗
D8.4대조·점검법령·규정·서식·인용·근태·보안 기준과 대조해 확인할 대상을 먼저 골라 주는 내부 운영 블록이다. "최종 판단은 사람"이 가장 자주 붙는다.81↗
D8.5취합·정산부서별 자료를 모으고 엑셀·한셀을 합치고 정산하는 내부 운영 블록이다. 서무의 핵심 반복 업무이며 B0 문서·엑셀 자동화와 A10이 전형 부품이다.36↗
D8.6분배·이관접수된 문서·민원을 담당자·부서로 보내는 내부 운영 블록이다. 대민 Triage(D4)의 내부 버전이며 C2 라우터가 붙는 첫 자리다.7↗
D8.7인수인계·지식 보존전임자 파일 더미를 업무·월별 정리본으로 바꾸고 결정·전례를 남기는 내부 운영 블록이다. 공직 순환보직이 만드는 한국 특유의 블록이다.37↗
D8.8보호·정제공유·전송 전에 개인정보를 비식별하고, 생성 코드를 보안 기준으로 점검하고, 파일을 이중 보관하는 내부 운영 블록이다. C5의 업무 블록 버전이다.18↗
D8.9변환·서식HWP·HWPX·PDF·DOCX·엑셀 사이를 오가고 양식을 만드는 내부 운영 블록이다. A10 문서 어댑터가 서비스로 독립한 형태다.80↗
D8.10발간·홍보보도자료·카드뉴스·포스터·정보지를 기획부터 발행까지 만드는 내부 운영 블록이다. B7 콘텐츠 제작의 업무 블록 버전이다.22↗

X 안티패턴

패턴의도PAX 사용성좌
X1AI 스티커기존 화면에 요약·챗봇 버튼만 붙이고 업무 순서와 사람·AI의 역할 분담은 그대로 두어, AI가 있어도 업무 산출물이 바뀌지 않는 함정이다.4↗
X2설계도만 있는 운영위험도 분기·롤백·재학습 같은 운영 부품이 '예정'·'설계됨'으로만 등장하고 운영(시범 운영 포함) 기간에 한 번도 실행되지 않은 채 운영 체계를 갖췄다고 보고하는 함정이다.3↗
X3부서마다 챗봇같은 기관의 과제들이 각자 모델·벡터DB·프롬프트를 따로 만들어, 공유할 수 있는 기반 부품을 부서 수만큼 중복 구축하는 함정이다.0↗
X4단일 모델 인질상용 API 하나에 전 기능이 묶여 있어, 그 API가 멈추거나 바뀌면 무슨 일이 생기는지 아무도 답하지 못하는 함정이다.3↗
X5성능표만 있는 학습학습 모델의 정확도는 보고하지만 배포 후 수정률을 누가 집계해 무엇을 바꾸는지가 없어, 개선이 배포 시점에 멈추는 함정이다.0↗
X6데모웨어시연은 되지만 실데이터·권한·망 환경이 없어 현장에 놓을 수 없는 함정이다. 접점과 환경 조건을 먼저 못 박는 단계를 건너뛴 결과다.4↗
X7도구 설명 ≠ 실제 권한MCP 도구 설명은 '조회'인데 코드는 쓰기·실행 권한을 가져, 설명만 믿고 도구를 부르는 에이전트가 의도하지 않은 변경을 일으키는 함정이다.1↗
X8MCP 서버 개수 세기MCP 서버를 몇 개 만들었는지가 성과가 되고, 실제 업무에서 호출되는지·흐름이 바뀌었는지는 아무도 묻지 않는 함정이다.1↗
X9담당자와 함께 사라지는 도구개인이 만든 도구가 부서에 퍼졌지만 라이선스·저장소·인수인계가 없어, 만든 사람의 인사이동과 함께 멈추는 함정이다.15↗
X10평가 없는 RAG, RAG 없는 튜닝평가 세트 없이 검색을 붙여 '좋아진 것 같다'로 배포하고, 검색으로 풀릴 문제를 파인튜닝으로 푸는, 진행 경로를 건너뛰는 함정이다.6↗
X11처음부터 멀티에이전트하위 작업이 분리되지 않는데 에이전트를 여럿 두어 조정 비용만 늘리는 함정이다. 단일 에이전트로 되돌리면 더 잘 되는 경우가 많다.0↗
X12상한 없는 반영 루프생성자-비평가·반복 개선 루프에 최대 반복을 두지 않아, 품질은 그대로인데 토큰과 지연만 늘어나는 함정이다.0↗
X13도구 출력이 지시가 되는 에이전트검색 결과·첨부·API 응답을 읽은 모델이 그 안의 문장을 새 명령으로 받아 도구를 부르는 구조를, 탐지 필터 하나로 지키려는 함정이다.2↗
X14재생할 수 없는 사고잘못된 처분이 나갔는데 그때의 프롬프트·검색·도구 호출 순서를 아무도 복원하지 못하는 함정이다. 지표는 있는데 기록이 없다.0↗
X15빌린 성과표자체 운영 실측치 없이 벤더 상용 서비스의 KPI를 준용해 성과로 보고하는 함정이다. 태깅 피드백을 반영해 v0.6에 추가됐다.0↗
