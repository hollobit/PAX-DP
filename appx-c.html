부록 · 부록 C

용어집

카탈로그와 이 책에서 정해진 뜻으로 쓰는 용어를 모았다. 같은 말이 일상어와 다르게 쓰일 때는 이 뜻을 따른다.

이 장에서 얻을 것
  • 카탈로그 용어의 정의와 영문 병기를 확인한다
  • 용어가 가리키는 패턴으로 바로 이동한다
  • S·C 계층과 S·C 눈금자처럼 이름이 겹치는 용어를 구분한다

가나다순으로 싣고, 영문이나 기호로 시작하는 용어는 맨 뒤에 모았다. 정의는 카탈로그 v0.7.1, 태깅 기준(R1~R28), AX 성숙도 기준을 따르고, PAX 사이트의 페이지 이름과 설명은 2026년 10월의 사이트를 따른다. 관련 패턴 칸의 칩을 누르면 해당 패턴 프로필로 간다.

참고S와 C는 두 가지로 쓰인다. 패턴 id의 S·C는 보안 패턴 계층과 운영 컴포넌트 계층이고(S4, C2), AX 성숙도의 S·C는 업무 범위와 업무 완결성 눈금자다(S1~S5, C0~C5). 이 책은 눈금자를 가리킬 때 반드시 눈금자라고 쓴다.
